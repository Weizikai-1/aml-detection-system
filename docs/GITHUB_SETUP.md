# GitHub 仓库设置指南

完成以下步骤让项目仓库在 GitHub 上更专业、更易被发现。

## 1. 设置 About 区域

1. 打开 https://github.com/Weizikai-1/aml-detection-system
2. 点击仓库首页右侧齿轮图标（About 区域）
3. 填写:
   - **Description**: `基于 LangGraph 的 6-Agent 并行协同反洗钱检测系统 | GNN + LLM 双重深度分析 | 20条YAML规则 | FastAPI + Streamlit`
   - **Website**: (留空或填 Streamlit 演示链接)

## 2. 添加 Topics 标签

在 About 区域点击 "Manage topics"，添加:

```
aml  anti-money-laundering  langgraph  multi-agent  gnn  gat  graphsage
deepseek  llm  fastapi  streamlit  pytorch-geometric  fraud-detection
financial-crime  suspicious-transaction-report  paysim  machine-learning
```

## 3. 启用 GitHub Pages (可选)

如需在线展示 Streamlit 界面截图或文档:

1. Settings → Pages → Source: `main` branch, `/docs` folder → Save
2. 将 Streamlit 截图放入 `docs/screenshot.png`
3. 访问 `https://weizikai-1.github.io/aml-detection-system/`

## 4. 设置 Social Preview

1. Settings → Social preview → Upload image
2. 建议使用 Streamlit 仪表盘截图作为预览图
